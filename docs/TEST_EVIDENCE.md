# Implementation Evidence Checklist

Use this checklist to prepare authentic evidence for project reviews and the final report.

## Suggested evidence

- [ ] Application startup in the target environment
- [ ] Local model availability and a successful response
- [ ] Actual application interface or terminal interaction
- [ ] Camera test, if implemented
- [ ] Microphone and speaker test, if implemented
- [ ] Prototype photographs showing the assembled hardware
- [ ] Offline test with network access disabled, if offline operation is claimed
- [ ] Error-handling test for a missing model or device
- [ ] Test-results table with date, environment, expected result, actual result, and status

## Captions

For each screenshot or photograph, record:

- Evidence ID
- Date and environment
- Feature being demonstrated
- Steps performed
- What the evidence proves
- Any limitation or mock component

## Integrity

Use original evidence from the actual project. Clearly label mockups, simulated outputs, conceptual diagrams, and unimplemented features. Avoid including secrets, private conversations, account details, or identifiable information without consent.
